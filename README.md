## 🛠️ How to Run

Clone the repository:

```bash
git clone https://github.com/avinashverma39/Web_Development.git
```

Open the project folder:

```bash
cd Web_Development
```

For basic HTML/CSS/JavaScript projects, simply open the required `.html` file in your browser.

For a better development experience, you can use **VS Code** with the **Live Server** extension.
